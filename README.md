# PROJECT 14 — THE FUTURE DEPARTMENT
### A Studio for Things That Do Not Exist Yet

An independent speculative industrial design institution exploring counterfactual inventions, post-extractive machines, and civic instruments for emerging problems (2029–2045).

> **Speculative Classification:** Every invention documented in this project is explicitly labeled as a fictional, non-commercial speculative research artifact designed for critical inquiry.

---

## Visual & Architectural Identity
- **Palette:** Obsidian Black (`#0A0B0A`), Instrument Charcoal (`#141615`), Architectural Concrete (`#DCDCD6`), Technical Paper (`#F4F4F0`), and Anodized Acid Green (`#C6FF00`).
- **Typography:** Bold Architectural Grotesk (`Space Grotesk`), Editorial Sans (`Inter`), and Technical Monospace (`JetBrains Mono` with `tabular-nums`).
- **Layout:** Brutalist 12-column exposed-hairline grids, monumental project numbers (`014`–`036`), interactive ISO-128 orthographic CAD schematics, and structured metrology metadata.

## Four Distinct Pages
1. **Department (`/`)** — Studio manifesto, interactive *Counterfactual Horizon Scrubber (2030–2037)*, interactive 6-specimen preview ledger, and institutional design philosophy.
2. **Projects (`/projects`)** — Filterable archive of all six inventions by category, development phase, and search query, with a toggle between *Architectural Dossier Grid* and *Technical Specification Ledger Table*, plus inline expandable BOM/limitation drawers.
3. **Project Detail (`/projects/:id`)** — Complete engineering & ethical dossier for each of the six inventions (`/projects/tfd-014` through `/projects/tfd-036`), featuring a 4-plate photographic viewer with interactive hardware callout pins, full-screen keyboard-accessible Lightbox, interactive vector CAD schematic + live parameter simulator, and unredacted physical limitations & ethical dilemmas.
4. **Research (`/research`)** — 36-week counterfactual research methodology pipeline, fictional multidisciplinary research fellowship, filterable material coupon library (`MAT-01` to `MAT-06`), European foundry coordinates, and a validated curatorial loan requisition form.

## Six Speculative Inventions
- **TFD-014 // Lithic Memory Archive** (*Cold-Duration Civic Data Vessel*) — `CIVIC INFRASTRUCTURE`
- **TFD-019 // Atmospheric Taxonomist** (*Micro-Particulate Stratigraphy Sampler*) — `ECOLOGICAL INSTRUMENTS`
- **TFD-023 // Circadian Ballast** (*Grid-Synchronous Domestic Flywheel*) — `DOMESTIC ENERGETICS`
- **TFD-027 // Acoustic Territorializer** (*Phase-Nullifying Urban Monolith*) — `PUBLIC SPACE SYSTEMS`
- **TFD-031 // Mycelial Solder Reclaimer** (*Biological E-Waste Delaminator*) — `CIRCULAR MANUFACTURING`
- **TFD-036 // Tactile Treaty Terminal** (*Bilateral Resource Ledger*) — `GOVERNANCE HARDWARE`
